# C++ Programming Made Easy - Chapter 17

This repository contains the code examples and practice projects for Chapter 17 of the C++ Programming Made Easy series. The examples focus on fundamental C++ programming concepts and are organized as small, self-contained projects that can be opened and run in Visual Studio.

## Repository Overview

The repository includes:

- `CppME_Chapter17.cpp` — a minimal starter program generated by the Visual Studio C++ project template.
- `CppME_Chapter17.slnx` — the solution file for the chapter project.
- `CppME_Chapter17.vcxproj` and `CppME_Chapter17.vcxproj.filters` — the Visual Studio project files.
- Several example folders, such as:
  - `CppME_Chapter17_Example17.5`
  - `CppME_Chapter17_Example17.14`
  - `CppME_Chapter17_Example17.15`
  - `CppME_Chapter17_Example17.16`
  - `CppME_Chapter17_Example17.19`
  - `CppME_Chapter17_Example17.24`
  - `CppME_Chapter17_Example17.25`

Each example folder contains its own C++ source file and Visual Studio project metadata.

## Example 17.5

The first included example is `CppME_Chapter17_Example17.5`, which demonstrates a simple class definition:

- A `Student` class with:
  - `name` as a `std::string`
  - `age` as an integer
  - `displayInfo()` to print the stored values
- Standard C++ object usage:
  - instantiate a `Student`
  - assign values to its attributes
  - call a member function

This example illustrates the basic idea of encapsulating data and behavior inside a class.

## How to Build and Run

### Option 1: Visual Studio

1. Open `CppME_Chapter17.slnx` in Visual Studio.
2. Set the desired example project as the startup project if needed.
3. Build the solution with `Debug` or `Release` configuration.
4. Run the program using the Visual Studio debugger or by launching without debugging.

### Option 2: Command Line (MSVC tools)

If you have the Microsoft C++ toolchain installed, you can compile the example source files with `cl.exe` or use a developer command prompt.

Example:

```bat
cl /EHsc CppME_Chapter17_Example17.5\CppME_Chapter17_Example17.5.cpp
```

## Learning Goals

This chapter focuses on learning how to:

- declare and use classes
- define data members and member functions
- create objects from classes
- access and modify object attributes
- organize example programs into separate chapter-specific directories
